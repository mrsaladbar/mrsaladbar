### BlueHats: "An agent that builds agents" (hackathon winner)
Our team won an Ortus Solutions BoxLang + AI hackathon with **BlueHats**, an Agent Factory that turns a plain-English problem description into a complete, runnable BoxLang agent project. It chains an Architect agent (problem to spec), a deterministic Builder (spec to project files), and a QA agent that compiles and mock-tests the output, with a repair loop that fixes failures. I named the team and contributed to the project. The repository lives on a teammate's account: [LivinKevin/BlueHats](https://github.com/LivinKevin/BlueHats).
